📲 Cara Install Aplikasi ke HP

Agar web ini menjadi aplikasi di layar utama Handphone (HP):

  1. Buka link web ini menggunakan aplikasi Google Chrome (Android) atau Safari (iPhone).
  2. Tekan ikon Titik Tiga (⋮) di pojok kanan atas browser Chrome.
  3. Pilih menu "Tambahkan ke layar utama" (Add to Home screen) atau "Instal aplikasi" (Install app).
  4. Tekan Instal / Tambah, maka ikon aplikasi Warung Nenek Qiara akan muncul di menu HP.
